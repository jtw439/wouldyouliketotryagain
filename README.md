# Would You Like to Try Again?

Production deck site for the feature film by Michael Felker.

A single self-contained `index.html` (all images embedded). Fonts load from Google Fonts.

## Publish with GitHub Pages

1. Push these files to the root of a repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
